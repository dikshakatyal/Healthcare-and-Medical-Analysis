# 🏥 Healthcare CKD Prediction and EHR Analysis

An interactive Healthcare Analytics project focused on Chronic Kidney Disease (CKD) prediction and patient health analysis using Power BI and Streamlit dashboards.

---

# 📌 Project Overview

This project analyzes healthcare data to identify patterns and risk factors associated with Chronic Kidney Disease (CKD).  
The dashboard provides meaningful insights into patient conditions such as:

- Blood Pressure
- Diabetes Mellitus
- Hypertension
- Appetite
- Hemoglobin Levels
- Serum Creatinine
- Blood Glucose Random

The project combines:
- 📊 Power BI Dashboard
- 🌐 Streamlit Interactive Dashboard
- 📈 Healthcare Data Visualization
- 🧠 CKD Insights & Analytics

---

# 🚀 Key Features

✅ CKD vs Non-CKD Patient Analysis  
✅ Interactive Filters & Slicers  
✅ Healthcare KPI Cards  
✅ Blood Pressure Analysis  
✅ Hypertension & Diabetes Visualization  
✅ Appetite-based CKD Insights
